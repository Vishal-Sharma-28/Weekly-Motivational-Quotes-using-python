# Weekly Motivational Quotes Email Automation (Python)

## 📌 Description
This Python project automatically sends **weekly motivational quotes via email**.  
It selects a random quote from a text file and emails it to a recipient on a scheduled weekday using **SMTP (Gmail)**.

This project demonstrates **email automation, scheduling logic, file handling, and secure authentication**.

---

## 🚀 Features
- Sends **motivational quotes automatically once a week**
- Random quote selection from a text file
- Uses **Gmail SMTP server** with TLS encryption
- Configurable weekday for email scheduling
- Lightweight and easy to customize

---

## 🛠️ Technologies Used
- **Language:** Python  
- **Libraries:**  
  - `smtplib` – for sending emails  
  - `datetime` – for date and weekday checking  
  - `random` – for random quote selection  
- **Email Service:** Gmail SMTP
